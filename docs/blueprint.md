# **App Name**: CV Glass

## Core Features:

- CV Form: Form-based input for personal details, education, skills, experience and projects.
- Dynamic Content: Dynamic sections to add or remove experience and projects.
- Live Preview: Real-time resume preview on the side of the input form.
- PDF Download: One-click PDF download of the formatted resume.
- Template Selection: Selection of modern, professional resume templates.
- Theme Toggle: Dark/Light mode toggle with theme memory using localStorage.
- Local Storage: Save and Load resume data using localStorage with keyboard shortcuts (Ctrl+S to Save, Ctrl+P to download).

## Style Guidelines:

- Primary color: Soft Blue (#A0CFEC) for a calm, trustworthy aesthetic.
- Background color: Light gray (#F0F4F7) with low saturation to highlight the content, complements glassmorphism.
- Accent color: Pale violet (#B290D6), differing in saturation and brightness from primary to provide visual interest to highlights, selections, and controls.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, machined, neutral look. Note: currently only Google Fonts are supported.
- Apply glassmorphism to panels: frosted glass effects, blurred backgrounds, and subtle gradients.
- Employ a neatly spaced layout with visually appealing cards or panels. Add a header with app title and icon and a sticky footer with credits.
- Incorporate smooth transitions and subtle hover animations to enhance user interaction.
